# Bloom-Treppe: Säure-Base-Chemie

Differenzierte Lernapp zum Kapitel Säure-Base-Chemie (Buch S. 103–113).
Fünf Themen, jeweils als Treppe nach Blooms Lernzieltaxonomie:
Stufen 1–3 bilden die Basis für alle, Stufen 4–6 die Erweiterung.

- Läuft komplett im Browser, ohne Anmeldung und ohne Server.
- Der Lernfortschritt wird nur lokal im Browser der Lernenden gespeichert (localStorage).
  Es werden keine Daten übertragen; auch die Schriften liegen im Ordner `fonts/`.
- Inhalte lassen sich in der App unter „Für Lehrkräfte“ als JSON anpassen.

Schriften: Atkinson Hyperlegible und Bricolage Grotesque, beide unter SIL Open Font License.
